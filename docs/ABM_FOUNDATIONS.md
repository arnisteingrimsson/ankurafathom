# M4 ABM foundations

The first native spatial increment provides a single-occupancy integer `GridSpace` and a one-/two-/three-dimensional `ContinuousSpace` with uniform bins. Both have stable-ID queries, independent snapshots, bounded or periodic coordinates, sorted neighborhood results, and transactional movement batches. Grid swaps are simultaneous; continuous agents may share positions.

Normal and sanitizer tests compare neighborhoods to exhaustive distance calculations across small wrapped/bounded lattices, Moore/von Neumann neighborhoods, 1–3 continuous dimensions, multiple bin widths, and several radii. Tests also cover collisions, duplicate movement requests, nonfinite/out-of-bounds positions, snapshot isolation, co-located agents, and partial periodic bins. Tiny domains with bin-width division underflow still use one bin.

```sh
ctest --test-dir build --output-on-failure -R '^abm_'
```

`CsrNetwork` now provides directed/undirected simple graphs, stable IDs, sorted outgoing adjacency, independent snapshots, and atomic edge edits. Missing endpoints, loops, duplicates and overlapping edits fail without changing the graph. Erdős–Rényi, Watts–Strogatz and Barabási–Albert generators use explicit Philox contexts and unbiased integer choices. Their exact initial graphs, draw traversal, supported parameter ranges and snapshot lifetimes are specified in [semantics](SEMANTICS.md#abm-networks-and-bounded-message-topics). Native tests compare CSR edits to an independent adjacency matrix and cover generator endpoint cases, edge counts, connectivity, replay and declaration-order invariance. [Declarative graph generators](ABM_GRAPH_GENERATORS.md) now pass 51 predeclared statistical/analytical gates across nine cases and 4,608 graphs per engine against pinned NetworkX, plus 2,808 exact addressed CLI observations.

`TopicBroker<Payload>` adds bounded named topics, direct and broadcast delivery, stable sender/sequence ordering, explicit flush boundaries and transactional publication. Overflow, unknown topics, duplicate sequences and failed payload copies preserve pending and visible batches. All 24 permutations of a four-message batch produce the same delivery. Consumers can publish replies while iterating the current visible batch; a regression test caught and fixed publication invalidating that view. Successful flush replaces the visible batch.

Independent foundation checks now run against Mesa 3.5.1 and NetworkX 3.7 with [exact dependency pins](../tests/oracles/abm/requirements.txt). The [predeclared input plan](../tests/oracles/abm/foundation_plan.py) contains 26 cases and **7,504 exact neighborhood comparisons**: ten bounded/periodic grids (including one-cell and narrow domains), eight 2D continuous cases with several bin widths and co-located agents, and eight directed/undirected graphs. Every case checks both initial and moved/edited state. Integer grid swaps remove all movers before placement in the Mesa adapter; continuous queries include the center and filter only the querying ID, preserving co-located neighbors. Graph neighborhoods use Mesa `NetworkGrid` over NetworkX `Graph`/`DiGraph`. Native 1D/3D spaces remain covered by exhaustive distance tests, not this 2D Mesa reference.

The [reference adapter](../tests/oracles/abm/foundation_oracle.py) delegates neighborhood calculations to the [Mesa space API](https://mesa.readthedocs.io/stable/apis/space.html). Frozen evidence records input, adapter and dependency hashes. Offline CTest checks case/phase/query coverage, exact ordered identities, valid unique neighbors and metadata; corruption tests reject truncated, reordered, stale and altered reports. Regeneration in the isolated pinned environment matches the frozen reference. A separate CI job is configured to regenerate it; remote CI has not run.
